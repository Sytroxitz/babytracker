# Repository work rule

- Update `frontend/CHANGELOG.md` whenever you change this repository. Describe every user-visible change in plain German; also note relevant fixes or technical changes briefly.
- Keep the newest release section at the top. Add new changes to that section while a release is in progress. When starting a later release, create a new `##` section above the older ones and leave older sections intact.
- The app reads the newest section to show its release notes once per app version. Keep each section's first line as a `##` heading and its changes as `-` bullet points. Check the changelog before declaring work complete.
